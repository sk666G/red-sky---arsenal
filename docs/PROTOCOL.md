# Red Sky — Protocol

The wire format. Anyone can build a compatible implant from this spec.

## Outer packet

Every packet is:

    [ 4 bytes magic "RSKY" ]
    [ 1 byte  version = 1 ]
    [ 1 byte  msg_type ]
    [ 12 bytes AES-GCM nonce ]
    [ 2 bytes ciphertext length, big-endian ]
    [ N bytes ciphertext + 16-byte GCM tag ]

The AES-GCM Additional Authenticated Data (AAD) is the 4-byte magic "RSKY".
The key is 32 bytes (AES-256). It is unique per bot, generated by the builder, stored in Data/botnet.sqlite.

## Plaintext payload

After decryption the payload is JSON:

    {
      "type": <int>,
      "payload": { ... },
      "ts": <float unix seconds>
    }

## Message types

    0x01  CHECKIN   first contact with environment info
    0x02  TASK      server to beacon, list of tasks to run
    0x03  RESULT    beacon to server, task output
    0x04  PING      beacon poll, no payload
    0x05  PONG      reserved
    0x06  KILL      server to beacon, self-destruct
    0x07  CONFIG    server to beacon, config update

## Beacon request framing

Every POST to /api/beacon has body:

    {bot_id}
    {aes_key_hex}
    {hex-encoded packet}

Three lines. The server decrypts using the key on the second line and looks up the bot by id on the first.

## Result POST framing

Same three-line body but sent to /api/result:

    {bot_id}
    {aes_key_hex}
    {hex-encoded packet}

## CHECKIN payload

    {"hostname": str, "user": str, "os": str, "arch": str,
     "pid": int, "local_ip": str, "campaign": str}

## TASK payload

    {"tasks": [{"id": str, "command": str, "args": {...}}, ...]}

The beacon loop parses tasks, dispatches each, and POSTs a RESULT.

## RESULT payload

    {"task_id": str, "output": str, "ok": bool}

## Task commands

    shell       args: {"cmd": "whoami"}
    list_procs  args: {}
    file_up     args: {"path": str, "data": base64}
    file_down   args: {"path": str}  returns FILE:base64
    screenshot  args: {}  returns SCREEN:base64 (w,h,bgra)
    persist     args: {"method": "runkey|schtask|startup"}
    whoami      args: {}
    sysinfo     args: {}
    kill        args: {}  beacon exits

## Notes

- Nonce is random 12 bytes per packet, generated by the sender.
- No padding; AES-GCM handles arbitrary length.
- The 2-byte length cap means max ciphertext is 65535 bytes, so max plaintext is about 65519 bytes.
- Tag is 16 bytes, appended to ciphertext inside the length field.
