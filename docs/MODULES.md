## Adding a module

**Core:** add a `regRegister(Module{Name: "...", Help: "...", Run: ...})` call inside an `init()` in `cmd/redsky-core/registry.go`. Run `make docs`.

**Agent:** drop a new file in `internal/agentfw/` that calls `Register()` from `init()`. Run `make docs`.
